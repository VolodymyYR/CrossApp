## Предметна область

Замовлення.

Призначення застосунку — оформлення замовлень і підрахунок їхньої вартості.

Основні сутності:

- Customer — клієнт, який оформлює замовлення.
- Product — товар із назвою та ціною.
- Order — замовлення клієнта.
- OrderLine — позиція замовлення з товаром і його кількістю.

Я обрав цю предметну область, оскільки мені зрозумілий процес
оформлення замовлень в інтернет-магазині.

## Лабораторна робота 1

Я створив solution і консольний проєкт.
Програма виводить інформацію про операційну систему,
архітектуру процесу, runtime і робочі каталоги.

## Запуск

Команди виконую з кореня репозиторію:

```powershell
dotnet build
dotnet run --project src/Cli
```
