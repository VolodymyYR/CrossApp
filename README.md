# CrossApp

Навчальний проєкт з крос-платформного програмування.

## Автор

Яремкович Володимир, група ФЕІ-33.

## Предметна область

Замовлення.

Призначення застосунку — оформлення замовлень і підрахунок їхньої вартості.

Основні сутності:

- Customer — клієнт, який оформлює замовлення.
- Product — товар із назвою та ціною.
- Order — замовлення клієнта.
- OrderLine — позиція замовлення з товаром і його кількістю.

Я обрав цю предметну область, оскільки мені зрозумілий процес
оформлення замовлень в інтернет-магазині.

## Лабораторна робота 1

Я створив solution і консольний проєкт.
Програма виводить інформацію про операційну систему,
архітектуру процесу, runtime і робочі каталоги.

## Запуск

Команди виконую з кореня репозиторію:

```powershell
dotnet build
dotnet run --project src/Cli
```

## Додаткове завдання

Я опублікував застосунок у конфігурації Release як self-contained
для двох RID: win-x64 та linux-x64.

### Порівняння розмірів

Я підсумував розміри всіх файлів у кожному каталозі publish.
1 MiB = 1 048 576 байтів.

| RID | Розмір у байтах | Розмір у MiB |
|---|---:|---:|
| win-x64 | 80583509 | 76.85 |
| linux-x64 | 82670401 | 78.84 |

Публікація linux-x64 більша за win-x64 на 1.99 MiB.

Розміри можуть відрізнятися, оскільки публікації містять
різні платформні файли середовища виконання .NET.

### Формати виводу

Я додав перевірку прапорця --json.
Без прапорця програма виводить дані таблицею.
Із прапорцем вона виводить ті самі дані одним JSON-рядком
за допомогою System.Text.Json.

Команда звичайного запуску:

    dotnet run --project src/Cli

Команда запуску з JSON:

    dotnet run --project src/Cli -- --json
